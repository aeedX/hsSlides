# HsSlides: мини-аналог PowerPoint на Haskell

Редактор презентаций. Модель документа, операции над ним, история отмены,
сохранение в файл, вёрстка слайдов и HTTP-сервер написаны на Haskell.
Интерфейс открывается в браузере; JavaScript там нужен только для
перетаскивания мышью, маркеров размера и горячих клавиш (все действия, кроме
этого, работают и обычными формами).

## Запуск

```
cabal run hs-slides                    # файл presentation.hsl, порт 8080
cabal run hs-slides -- talk.hsl 9000   # свой файл и порт
```

Откройте в браузере адрес, который напечатает программа:
`http://127.0.0.1:8080/`. Остановка: Ctrl+C.

Без cabal (нужен установленный пакет `network`):

```
ghc -O1 -threaded -isrc -outputdir build -o hs-slides src/Main.hs
./hs-slides
```

Требуется GHC 9.4 или новее. Пакеты: `base`, `bytestring`, `directory`,
`filepath`, `text` (входят в GHC) и `network` 3.1–3.2.

## Что умеет

* Слайды: новый слайд с макетом (пустой, титульный, заголовок и текст),
  дублирование, удаление, перемещение выше и ниже, цвет фона.
* Объекты: текст, прямоугольник, скруглённый прямоугольник, овал,
  треугольник, линия, картинка (файл на диске или ссылка `http(s)`).
* Свойства: текст, размер, шрифт, жирный и курсив, выравнивание, цвет текста,
  заливка, контур и его толщина, отражение линии и треугольника,
  положение и размер числами.
* Мышь: перетаскивание, восемь маркеров изменения размера, двойной щелчок
  переводит к полю текста.
* Клавиши: стрелки сдвигают на 2 пикселя (с Shift на 20), Delete удаляет,
  Ctrl+D дублирует, Ctrl+Z и Ctrl+Y отменяют и возвращают, Esc снимает
  выделение, PageUp и PageDown листают слайды.
* Отмена и возврат: до 200 шагов, включая операции со слайдами и название.
* Показ: кнопка «Показ». Стрелки, пробел, Backspace, Home, End, щелчок мышью,
  F включает полный экран, Esc возвращает в редактор.
* Экспорт: кнопка «Экспорт в HTML» даёт один файл со всеми слайдами и
  встроенными картинками, он работает без сервера и без интернета. Чтобы
  получить PDF, откройте этот файл в браузере и выберите печать, затем
  «Сохранить как PDF»: каждый слайд будет на своей странице 16:9.
* Автосохранение в файл после каждого изменения (запись через временный файл).

## Файл презентации

Первая строка `HSSLIDES 1`, дальше значение типа `Deck`, записанное через
`show` (не-ASCII символы экранируются, поэтому файл не зависит от кодировки).
Руками его править не рекомендуется. При загрузке цвета и размеры
проверяются и приводятся к допустимым.

## Устройство

| Модуль | Назначение |
| --- | --- |
| `Deck.hs` | типы `Deck`, `Slide`, `Element`, чистые операции, чтение и запись файла |
| `Editor.hs` | состояние редактора, история отмены, обработка действий формы |
| `Render.hs` | HTML слайдов, страница редактора, страница показа и экспорта, base64 |
| `Assets.hs` | CSS и JavaScript, встроенные в программу |
| `Http.hs` | небольшой HTTP-сервер на сокетах, разбор форм |
| `Main.hs` | маршруты, проверки безопасности, запуск |

## Безопасность локального сервера

Сервер слушает только `127.0.0.1`, отклоняет запросы с чужим заголовком `Host`
(защита от подмены DNS) и изменяющие запросы с чужим `Origin` (защита от
запросов с посторонних сайтов). Картинки с диска читаются только с
расширениями изображений и размером до 50 МБ.

## Ограничения

* Один документ и один пользователь на запущенную программу; две вкладки
  показывают одно и то же состояние.
* Файлы `.pptx` не читаются и не создаются. Нет анимаций, переходов, таблиц,
  диаграмм и заметок докладчика.
* Шрифты берутся из системы браузера (три семейства: без засечек, с засечками,
  моноширинный).
* Относительные пути к картинкам отсчитываются от каталога, где запущена
  программа.
* Проверено на Linux (Ubuntu 24.04, GHC 9.4.7, Chromium 153). На Windows и
  macOS не запускалось.
